# Linux System Monitor 🐧

A lightweight Python utility designed to monitor critical Linux system performance metrics in real-time.

## Features 🚀
- **CPU Usage Tracking:** Monitors overall processor load.
- **RAM Monitoring:** Displays total, used, and available memory.
- **Disk Usage Analysis:** Checks available storage space on disk partitions.

## Requirements 📦
- Python 3.x
- `psutil` library
